### 统一风格要求

**配色**（必须与站点设计语言一致，取自项目 CSS 变量）

**风格**
- 扁平化，不要 3D、不要阴影、不要渐变、不要默认蓝色办公风
- 留白充足，元素之间保持呼吸感
- 圆角统一（8px 左右），描边统一 1.5px
- 中文用微软雅黑，代码与技术名词用 Consolas
- 同一层级的元素字号、配色、间距必须一致

**输出规格**
- PNG 格式，**300 DPI 以上**（1600px 宽起步）
- 中文不得出现方框或回退字体
- 字体、颜色要在所有图之间保持一致

**工具**由你选择：matplotlib、graphviz、mermaid、SVG 转 PNG、draw.io 均可，
只要满足上面的输出规格。

### 逐图内容要求

**图 1　整体系统架构**

必须体现：
- 顶部是浏览器（原生 JS + CSS，无构建步骤）
- 中间是 CloudBase 网关，向下分出两条独立链路
- 业务链路：云函数 `yard-api`（Event）→ PostgreSQL
- AI 链路：云函数 `ai-stream`（HTTP，SSE）→ 对话模型 / 向量模型 / 视觉模型
- 数据层：PostgreSQL（含 pgvector 扩展）+ 对象存储
- **两条链路要画成相互独立**，体现"AI 异常不影响业务请求"

**图 2　AI 请求链路与降级路径**

必须体现（这是一个含三个分支的流程图）：
- 主链路：访客提问 → 解析模型 Key
- 分支一（无 Key）：进入演示模式，返回内置示例回复
- 分支二（有 Key）：进入工具循环（最多三轮）→ 模型作答（SSE 流式）
- 分支三（模型不支持工具调用）：退回档案注入模式，不再调用工具
- 分支标签要清楚，连线不要交叉

**图 3　Agent 工具调用时序**

四泳道时序图：访客 / ai-stream / 对话模型 / 数据库。
消息顺序（实测一次真实调用）：
1. 访客 → ai-stream：提问
2. ai-stream → 对话模型：携带工具清单请求
3. 对话模型 → ai-stream：返回 4 个 tool_calls
4. ai-stream → 数据库：执行查询（经特权通道）
5. 数据库 → ai-stream：返回检索结果
6. ai-stream → 对话模型：带上结果再次请求
7. 对话模型 → ai-stream：生成最终回答
8. ai-stream → 访客：SSE 流式下发

底部标注实测调用的四个工具名：
`search_pets` → `check_requirement_gaps` → `get_pet_profile` → `get_adoption_policy`
并注明：三轮为上限，最后一轮不再提供工具。

**图 4　数据访问的两条通道**

必须体现：
- 通道一：前端 → CloudBase 网关 → 数据库，**受 RLS 策略约束**
- 通道二：云函数 → 腾讯云 OpenAPI（ExecutePGSql）→ 数据库，**以表属主身份运行，绕过 RLS**
- 明确标出哪些表只能走通道二：`applications`、`yard_administrators`、
  `yard_settings`、`knowledge_chunks`、`pet_photo_vectors`
- 这张图要能说明一个真实缺陷：云函数内部误用了匿名身份的数据库客户端，
  导致后台多个功能长期不可用

**图 5　RAG 检索与按需重建索引**

必须体现两条流：
- **写入流**：宠物档案 / 领养要求 / 领养政策 / 回访记录 → 按字段切块 → 批量向量化
  → 存入 `knowledge_chunks`（1024 维，HNSW 余弦索引）
- **查询流**：访客提问 → 向量化 → pgvector 余弦检索取 Top-K → 相似度阈值过滤（0.3）
  → 命中片段带来源标签交给模型
- **旁支**：检索前检查索引是否落后于档案更新时间，落后则重建

**图 6　数据模型与权限边界**

11 张表分三组画出，并标注权限：
- 业务表（7 张）：`pets`、`pet_media`、`pet_updates`、`applications`、
  `application_events`、`yard_administrators`、`yard_settings`
- 限频表（1 张）：`rate_limit_events`
- 向量表（2 张）：`knowledge_chunks`、`pet_photo_vectors`
- 权限标注三档：匿名可读 / 仅管理员 / 仅特权通道

**图 7　向量模型语义方向实测**

数据图，用真实测量值：
- 领养相关两句之间的余弦相似度 **0.4447**
- 领养相关与无关句之间 **0.2566**
- 注明模型 `kinfra-text-embedding-0.6b`，输出 1024 维，单次调用约 350ms
- 说明：相关相似度高于无关相似度，说明检索方向正确
