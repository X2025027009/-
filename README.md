# 成都猫狗小院网站

这是成都猫狗小院的第一版可运行网页原型，使用原生 HTML、CSS、JavaScript 构建，无需安装前端框架即可查看。

## 本地查看

可以直接双击 `index.html`，也可以在此文件夹中启动一个本地静态服务器：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 当前已包含

- 响应式首页和手机端布局
- 宠物筛选与详情弹窗
- 待领养正式申请
- 暂不适合领养宠物的预约申请
- 已领养档案与回访更新展示
- 浏览器本地保存的管理员演示后台
- 宠物资料编辑、状态修改和示例图片上传
- 申请记录管理
- 联系方式设置

## 说明

当前后台是前端演示版，数据保存在当前浏览器的 LocalStorage 中。正式上线时，需要接入云端数据库、管理员账号登录、图片/视频存储和网站域名。
